# Feature Specification: 홈 화면

**Feature Branch**: `001-home-screen`

**Created**: 2026-05-16

**Status**: Clarified

**Input**: User description: "홈 화면 구현 - 배너, 급상승 랭킹, 성분 가이드, 하단 네비게이션 바"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 홈 화면 배너 조회 및 상세 이동 (Priority: P1)

사용자가 홈 화면에 진입하면 상단에 배너 슬라이더가 표시된다. 배너는 자동으로 일정 간격마다 옆으로 넘어가며, 현재 위치 인디케이터(예: 2/5)가 표시된다. 사용자가 배너를 클릭하면 해당 배너의 상세 페이지로 이동한다.

**Why this priority**: 홈 화면의 가장 큰 시각적 영역을 차지하며, 첫 인상을 결정하는 핵심 요소

**Independent Test**: 배너 데이터를 불러와 슬라이더로 표시하고, 클릭 시 상세 페이지로 이동하는 것을 독립 테스트 가능

**Acceptance Scenarios**:

1. **Given** 홈 화면에 진입했을 때, **When** 배너 데이터가 로드되면, **Then** 배너 이미지가 슬라이더 형태로 표시되고 현재 위치 인디케이터(N/전체)가 보인다
2. **Given** 배너가 표시된 상태에서, **When** 설정된 시간(초)이 경과하면, **Then** 자동으로 다음 배너로 넘어간다
3. **Given** 배너가 표시된 상태에서, **When** 사용자가 배너를 클릭하면, **Then** 해당 배너의 상세 페이지로 이동한다
4. **Given** 마지막 배너에 도달했을 때, **When** 자동 전환 시간이 경과하면, **Then** 첫 번째 배너로 돌아간다 (무한 루프)
5. **Given** 사용자가 배너를 수동으로 스와이프했을 때, **When** 스와이프가 완료되면, **Then** 자동 전환 타이머가 리셋되어 4초 후 다시 자동 전환이 시작된다

---

### User Story 2 - 급상승 랭킹 제품 조회 및 이동 (Priority: P1)

사용자가 홈 화면에서 "현재 급상승 랭킹" 섹션을 볼 수 있다. 제품 카드에는 순위 뱃지(1, 2, 3), 제품 이미지, 회사명, 제품명, 별점, 리뷰 수가 표시된다. 각 카드를 클릭하면 제품 상세 페이지로 이동하고, 섹션 헤더("현재 급상승 랭킹" + 화살표)를 클릭하면 제품 리스트 페이지로 이동한다.

**Why this priority**: 사용자가 인기 제품을 즉시 확인할 수 있는 핵심 기능

**Independent Test**: 랭킹 API에서 데이터를 불러와 카드를 렌더링하고, 각 클릭 동작이 올바른 페이지로 이동하는지 테스트 가능

**Acceptance Scenarios**:

1. **Given** 홈 화면에 진입했을 때, **When** 랭킹 데이터가 로드되면, **Then** 순위 뱃지와 함께 전체 랭킹 제품 카드가 가로 스크롤(가상화 적용) 형태로 표시된다
2. **Given** 제품 카드가 표시된 상태에서, **When** 카드에 제품 이미지, 회사명, 제품명, 별점(★), 리뷰 수가 표시된다, **Then** 모든 정보가 올바르게 렌더링된다
3. **Given** 제품 카드를 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 해당 제품의 상세 페이지로 이동한다
4. **Given** "현재 급상승 랭킹" 헤더 또는 화살표(>)를 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 제품 리스트 페이지로 이동한다

---

### User Story 3 - 성분 가이드 태그 탐색 및 이동 (Priority: P2)

사용자가 홈 화면에서 "성분 가이드" 섹션을 볼 수 있다. 성분명이 태그(칩) 형태로 나열되어 있으며, 각 태그를 클릭하면 해당 성분의 상세 페이지로 이동한다. "성분 가이드" 헤더 + 화살표를 클릭하면 성분 가이드 리스트 페이지로 이동한다.

**Why this priority**: 사용자에게 성분 정보 탐색 경로를 제공하는 부가 기능

**Independent Test**: 성분 태그 렌더링 및 클릭 시 올바른 상세 페이지로 이동하는지 테스트 가능

**Acceptance Scenarios**:

1. **Given** 홈 화면에 진입했을 때, **When** 성분 가이드 섹션이 렌더링되면, **Then** 성분명이 태그(칩) 형태로 여러 줄에 걸쳐 표시된다
2. **Given** 성분 태그를 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 해당 성분의 가이드 상세 페이지로 이동한다
3. **Given** "성분 가이드" 헤더 또는 화살표(>)를 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 성분 가이드 리스트 페이지로 이동한다

---

### User Story 4 - 글로벌 네비게이션 (헤더 + 하단 바) (Priority: P1)

사용자가 화면 상단에서 로고와 검색 아이콘을 볼 수 있다. 로고 클릭 시 홈으로 돌아오고, 검색 아이콘 클릭 시 검색 페이지로 이동한다. 하단 바에는 카테고리, 홈, 마이페이지 탭이 있다. 카테고리 클릭 시 왼쪽에서 사이드 네비게이션이 오버레이로 나타나고, 마이페이지 클릭 시 마이페이지로 이동한다.

**Why this priority**: 모든 화면에서 공통으로 사용되는 네비게이션 구조

**Independent Test**: 각 네비게이션 요소의 클릭 동작과 페이지 이동을 독립적으로 테스트 가능

**Acceptance Scenarios**:

1. **Given** 홈 화면에 진입했을 때, **When** 헤더가 렌더링되면, **Then** 왼쪽에 로고, 오른쪽에 검색 아이콘이 표시된다
2. **Given** 로고를 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 홈 화면(/)으로 이동한다
3. **Given** 검색 아이콘을 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 검색 페이지로 이동한다
4. **Given** 하단 바가 렌더링되었을 때, **When** 카테고리, 홈, 마이페이지 3개 탭이 표시된다, **Then** 현재 활성 탭(홈)이 시각적으로 구분된다
5. **Given** 카테고리 탭을 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 왼쪽에서 카테고리 사이드 네비게이션이 오버레이로 나타난다
6. **Given** 카테고리 사이드 네비게이션이 열려 있을 때, **When** 오버레이 배경을 탭하거나 X 버튼을 누르면, **Then** 사이드 네비게이션이 닫힌다
7. **Given** 마이페이지 탭을 클릭했을 때, **When** 클릭 이벤트가 발생하면, **Then** 마이페이지로 이동한다

---

### Edge Cases

- 배너 이미지 로딩이 느릴 때: 스켈레톤 로딩 상태 표시
- 사용자가 배너를 수동 스와이프한 직후: 자동 전환 타이머가 리셋되어 4초 후 다시 자동 전환 시작
- **(하드코딩 단계 적용 안 됨)** 백엔드 연동 시:
  - 배너/랭킹/성분 가이드 데이터가 0건일 때: 스켈레톤 로딩 표시 후, 데이터 없음 시 재시도 버튼 표시
  - 네트워크 오류로 API 호출이 실패했을 때: 스켈레톤 로딩 후 실패 시 재시도 버튼 표시

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 `https://dasii.kr/` 엔드포인트에서 배너 데이터를 조회하여 표시해야 한다 (MUST)
- **FR-002**: 배너는 4초(4000ms) 간격으로 자동으로 다음 배너로 전환되어야 한다 (MUST). 향후 조정 가능하도록 단일 상수(`BANNER_AUTO_INTERVAL_MS`)로 관리한다.
- **FR-003**: 배너 클릭 시 `/banners/` 엔드포인트에서 메인 배너 목록을 조회하여 해당 배너의 상세 내용을 새 페이지에 표시해야 한다 (MUST)
- **FR-004**: 시스템은 `/products/ranking/` 엔드포인트에서 급상승 랭킹 데이터를 조회하여 표시해야 한다 (MUST)
- **FR-005**: 랭킹 제품 카드에는 순위 뱃지, 제품 이미지, 회사명, 제품명, 별점, 리뷰 수가 표시되어야 한다 (MUST)
- **FR-006**: 제품 카드 클릭 시 `/products/{id}/` 엔드포인트를 통해 제품 상세 페이지로 이동해야 한다 (MUST)
- **FR-007**: "현재 급상승 랭킹" 헤더 + 화살표 클릭 시 제품 리스트 페이지로 이동해야 한다 (MUST)
- **FR-008**: 성분 가이드 섹션에 성분명이 태그(칩) 형태로 표시되어야 한다 (MUST)
- **FR-009**: 성분 태그 클릭 시 `/ingredients/guides/{id}` 엔드포인트를 통해 해당 성분 상세 페이지로 이동해야 한다 (MUST)
- **FR-010**: "성분 가이드" 헤더 + 화살표 클릭 시 성분 가이드 리스트 페이지로 이동해야 한다 (MUST)
- **FR-011**: 상단 헤더에 로고(좌측)와 검색 아이콘(우측)이 표시되어야 한다 (MUST)
- **FR-012**: 로고 클릭 시 홈 화면으로 이동해야 한다 (MUST)
- **FR-013**: 검색 아이콘 클릭 시 검색 페이지로 이동해야 한다 (MUST). 검색 엔드포인트: `/products/search/`
- **FR-014**: 하단 바에 카테고리, 홈, 마이페이지 탭이 표시되어야 한다 (MUST)
- **FR-015**: 카테고리 탭 클릭 시 왼쪽에서 사이드 네비게이션이 오버레이로 나타나야 한다 (MUST)
- **FR-018**: 카테고리 사이드 네비게이션은 오버레이 배경 탭 또는 X 버튼으로 닫을 수 있어야 한다 (MUST)
- **FR-019**: 배너 수동 스와이프 시 자동 전환 타이머가 리셋되어야 한다 (MUST)
- **FR-020**: 랭킹 섹션은 가로 스크롤로 전체 랭킹 제품을 가상화 리스트로 표시해야 한다 (MUST)
- **FR-021**: 각 섹션은 로딩 시 스켈레톤 UI를 표시해야 한다 (MUST)
- **FR-021a**: 백엔드 API 연동 단계에서 데이터 0건 또는 호출 실패 시 재시도 버튼을 제공해야 한다 (MUST, deferred — 하드코딩 단계에서는 생략)
- **FR-016**: 마이페이지 탭 클릭 시 마이페이지로 이동해야 한다 (MUST)
- **FR-017**: 로고/아이콘은 사용자가 `assets/`에 추가할 때까지 회색(gray-200) 플레이스홀더로 대체한다 (MUST)

### Key Entities

- **배너 (Banner)**: 홈 화면 상단 슬라이더에 표시되는 프로모션/이벤트 배너. 이미지, 제목, 상세 링크 포함
- **제품 (Product)**: 다이어트 보조제 제품. 이름, 회사명, 이미지, 별점, 리뷰 수, 순위 포함
- **성분 가이드 (Ingredient Guide)**: 다이어트 보조제 성분 정보. 성분명, 상세 설명 포함

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 홈 화면 진입 시 배너, 랭킹, 성분 가이드 3개 섹션이 모두 2초 이내에 표시된다
- **SC-002**: 배너 자동 전환이 설정된 간격에 맞춰 동작하며, 수동 터치 스와이프도 지원한다
- **SC-003**: 모든 클릭 가능한 요소(배너, 카드, 태그, 헤더, 네비게이션)가 올바른 페이지로 이동한다
- **SC-004**: 하단 바에서 현재 활성 탭이 시각적으로 구분된다
- **SC-005**: 카테고리 사이드 네비게이션이 부드러운 애니메이션과 함께 왼쪽에서 등장한다

## Clarifications

### Session 2026-05-16

- Q: API 실패 또는 데이터 0건 시 처리 방식 → A: 스켈레톤 로딩 후 실패 시 재시도 버튼 표시
- Q: 성분 가이드 태그 데이터 출처 → A: 백엔드 개발 전이므로 모든 데이터 하드코딩 처리
- Q: 배너 스와이프 시 자동 전환 동작 → A: 스와이프 후 자동 전환 타이머 리셋 (4초 후 재시작)
- Q: 카테고리 사이드 네비게이션 닫기 방식 → A: 오버레이 배경 탭 + X 버튼 둘 다 지원
- Q: 홈 화면 랭킹 제품 표시 개수 → A: 가로 스크롤(가상화)로 전체 랭킹 표시 (제한 없음)

## Assumptions

- 백엔드 API 개발 전이므로 모든 데이터(배너, 랭킹, 성분 가이드)는 하드코딩으로 처리한다
- 백엔드 API 미연동 단계에서는 에러/빈 상태 UI를 생략한다. FR-021a 재시도 UI는 백엔드 연동 피처에서 처리한다
- 배너 자동 전환 간격은 4초(4000ms)로 결정. `BANNER_AUTO_INTERVAL_MS` 상수로 관리하며 추후 조정 가능
- 랭킹 섹션은 가로 스크롤 가상화 리스트로 전체 랭킹을 표시한다
- 검색 페이지, 제품 리스트 페이지, 제품 상세 페이지, 성분 상세 페이지, 마이페이지는 별도 피처로 구현되며, 이 스펙에서는 해당 페이지로의 라우팅만 담당한다
- UI 컴포넌트는 shadcn/ui를 사용한다
- 로고 및 아이콘 에셋은 사용자가 `src/assets/`에 직접 추가하며, 구현 시점에는 gray-200 플레이스홀더를 사용한다
